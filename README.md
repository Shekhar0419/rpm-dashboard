# 📖 Overview

Remote Patient Monitoring (RPM) Platform is a full-stack healthcare application that enables clinicians to remotely monitor patient health metrics through interactive dashboards, secure authentication, real-time visualizations, and longitudinal patient records.

The platform demonstrates how healthcare organizations can centralize patient monitoring, improve clinical decision-making, and reduce unnecessary hospital visits through digital health technologies.

The application includes:

- Secure login for healthcare users
- Doctor dashboard
- Patient dashboard
- Individual patient profile
- Vital sign visualization
- Historical monitoring
- Healthcare analytics
- Interactive charts
- CSV-driven healthcare dataset

# ✨ Key Features

## Doctor Dashboard

- View all registered patients
- Search patient records
- Monitor health metrics
- Review historical measurements
- Navigate to patient profiles

---

## Patient Dashboard

Patients can review:

- Blood Pressure
- Heart Rate
- Blood Glucose
- Oxygen Saturation
- Historical trends

---

## Patient Details

Each patient page provides:

- Demographic information
- Current vital signs
- Historical measurements
- Trend visualization
- Clinical indicators

---

## Healthcare Analytics

Interactive charts visualize:

- Vital sign trends
- Blood pressure changes
- Heart rate history
- Glucose monitoring
- Oxygen saturation

---

## Authentication

Role-based login supports:

- Doctor access
- Patient access
